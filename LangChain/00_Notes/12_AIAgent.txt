# AI Agent in LangChain

An AI agent is a system that uses an LLM to decide what actions to take, uses tools to perform those actions, observes the results, and continues until it can complete the user's goal or determine that it cannot.

For example:-

Suppose you ask:

Research the latest developments in LangChain, read a relevant article, and give me a summary with sources.

A basic LLM might answer from the information it already knows. An agent can decide to:

(i) Search the web for recent LangChain development.

(ii) Examine the search results.

(iii) Select a relevant article.

(iv) Read its content using a tool.

(v) Summarize the information.

Five characteristics of an AI agent are:-

(i) Goal driven

(ii) Autonomous planning

(iii) Tool using

(iv) Context aware

(v) Adaptive

- Is an AI agent just an LLM? (No)

An LLM is the reasoning and language-generation component. An agent system combines the LLM with tools, instructions, and an execution mechanism.

- Working

User request: "Find recent LangChain updates and summarize one useful source."

Receive the goal
    ↓
Decide what to do
    ↓
Execute the tool
    ↓
Observe the result
and decide again
    ↓
Produce the final answer

Think | decide → Act → Observe → Decide again → Finish.
