# Chains
A Chain is a sequence of components where the output of one component becomes the input of the next component.

Instead of manually calling each component separately, we connect them together.

Basic Flow
Input
  ↓
Prompt
  ↓
LLM
  ↓
Output Parser
  ↓
Final Output

- Why do we need Chains?

Without a chain, we have to manually handle every step:
    prompt = template.invoke({"topic": "Black Hole"})
    result = llm.invoke(prompt)
    output = parser.invoke(result)
    print(output)

With a chain:
    chain = template | llm | parser
    result = chain.invoke({
        "topic": "Black Hole"
    })
    print(result)

So chains make our code:
    Shorter
    Cleaner
    Easier to understand
    Easier to combine multiple components

- LCEL
The | operator is part of LCEL — LangChain Expression Language.
We use LCEL to construct chains.
For example:
    chain = prompt | llm | StrOutputParser()

# Sequential Chain
A Sequential Chain is a chain in which multiple steps are executed one after another in a fixed sequence.
The important idea is:
    The output of one step becomes the input of the next step.

Basic flow
Input
  ↓
Step 1
  ↓
Output 1
  ↓
Step 2
  ↓
Output 2
  ↓
Step 3
  ↓
Final Output

Suppose we want to build this chain:
    Topic
     ↓
    LLM
     ↓
    Report
     ↓
    LLM
     ↓
    Summary


prompt1 = PromptTemplate(
    template = "Generate information about this {topic}",
    input_variables = ['topic']
)

prompt2 = PromptTemplate(
    template = "Generate 5 small points from the following text \n {text}",
    input_variables = ['text']
)

chain = prompt1 | llm | parser | prompt2 | llm | parser

- Note
Sequential Chain using LCEL: Multiple components are connected using the | operator, where the output of each component automatically becomes the input of the next component.

- For printing the graph of the chain
chain.get_graph().print_ascii()

# Parallel Chains

A Parallel Chain is a chain where multiple independent tasks are executed at the same time, instead of waiting for one task to finish before starting the next.

Sequential vs Parallel

Sequential:

Input
  ↓
Task 1
  ↓
Task 2
  ↓
Task 3

Parallel:
                ┌→ Task 1 → Result 1
    Input ───────┼→ Task 2 → Result 2
                └→ Task 3 → Result 3

The key idea:
    In parallel chains, the tasks are independent, so they can run simultaneously.

Example:
    We will do two tasks independently.
    First task would generate the "Notes" from the prompt that we have given
    Second task would generate the "Quiz" based on the prompt

prompt1 = PromptTemplate(
    template = "Generate short and simple notes from the following text \n {text}",
    input_variables = ['text']
)

prompt2 = PromptTemplate(
    template = "Generate 5 short questions from the following text \n {text}",
    input_variables = ['text']
)

prompt3 = PromptTemplate(
    template = "Merge the provided notes and quiz into a single document \n notes -> {notes} & quiz -> {quiz}",
    input_variables = ['notes', 'quiz']
)

parser = StrOutputParser()

parallel_chain = RunnableParallel(
    {
        'notes' : prompt1 | llm | parser,
        'quiz' : prompt2 | llm | parser
    }
)

merge_chain = prompt3 | llm | parser

chain = parallel_chain | merge_chain


# Conditional Chain
A Conditional Chain is a chain where the next step is selected dynamically based on the input or output of a previous step.
Unlike a sequential chain, where the path is fixed:
  A → B → C
a conditional chain can choose:
              ┌→ B
  A → Condition┤
              └→ C

Simple real-world example
Suppose the user enters a question.

We first determine whether it is about Python or Java:
                      ┌→ Python Chain
  Question → Condition
                      └→ Java Chain
Only one branch is executed depending on the condition.

- Syntax
In modern LangChain, we commonly use RunnableBranch.
from langchain_core.runnables import RunnableBranch
Basic Syntax:
  branch_chain = RunnableBranch(
      (condition_1, chain_1),
      (condition_2, chain_2),
      default_chain
  )

Think of it like:
  if condition_1:
      chain_1
  elif condition_2:
      chain_2
  else:
      default_chain
