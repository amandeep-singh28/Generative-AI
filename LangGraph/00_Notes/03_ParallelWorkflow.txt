## (i) Cricket

- Runs
- Balls
- 4s
- 6s

Metrics:
- Strike Rate
- Runs in boundary %
- BPB (Balls per boundary)

These can be calculated parallelly.

### Workflow Diagram

START
  ├── Strike Rate ──┐
  ├── b% ───────────┼──> Summary ──> END
  └── bpb ──────────┘

### State

1. Runs
2. Balls
3. Fours
4. Sixes
5. SR (Runs / balls) × 100
6. BPB (balls / (fours + sixes))
7. Boundary-percent ((fours × 4 + sixes × 6) / runs) × 100
8. Summary

## Why partial state update in parallel workflows?

In parallel workflows, multiple nodes may execute simultaneously. If each node returns the entire state, they may overwrite each other's updates.

Each node should return only the field it updates.
