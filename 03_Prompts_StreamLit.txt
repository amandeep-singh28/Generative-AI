# What is Streamlit?

Streamlit is a Python framework used to quickly create interactive web applications for Python/ML/GenAI projects.

It allows us to create a UI directly from Python code.

# 1. Import Streamlit

import streamlit as st

st is the conventional alias used for Streamlit.

# 2. Display Heading

st.header("Researcher Tool")

Displays a heading in the web application.

Other commonly used functions:
- st.title()
- st.subheader()
- st.write()

# 3. Select Box

paper_input = st.selectbox(
    "Select Research Paper Name",
    ["Paper 1", "Paper 2", "Paper 3"]
)

Creates a dropdown menu.

The selected value is stored in:
paper_input

Similarly:
- style_input = st.selectbox(...)
- length_input = st.selectbox(...)

# 4. Text Input

user_input = st.text_input("Enter your prompt")

Creates a text field where the user can enter input.

The entered value is stored in:
user_input

# 5. Button

if st.button("Run"):
    result = llm.invoke(prompt)
    st.write(result.content)

st.button() creates an interactive button.

The code inside the if block executes when the user clicks the button.

# 6. Display Output

st.write(result.content)

Displays the result in the Streamlit UI.

# Why Use PromptTemplate Over f-strings?

1. Default validation
2. Reusable
3. LangChain ecosystem

## Default Validation (validate_template=True)

It checks whether the variables used in the prompt template match the variables provided in "input_variables".

Example:

from langchain_core.prompts import PromptTemplate

prompt = PromptTemplate(
    template="Explain {topic} to a {audience}",
    input_variables=["topic", "audience"],
    validate_template=True
)

If a required variable is missing or incorrectly defined, LangChain can raise an error.

## Reusable

A PromptTemplate can be saved as a JSON file:

template.save("template.json")

This allows the prompt template to be shared separately from the Python code.

The saved template can later be loaded:

from langchain_core.prompts import load_prompt

template = load_prompt("template.json")

Then we can use it normally:

prompt_template.invoke({
    "paper_input": paper_input,
    "style_input": style_input,
    "length_input": length_input
})

# Chatbot with Previous Context

llm = ChatOpenAI()
chat_history = []

while True:
    user_input = input("You: ")
    chat_history.append(user_input)

    if user_input == "exit":
        break

    result = llm.invoke(chat_history)
    chat_history.append(result.content)

    print("AI:", result.content)

print(chat_history)

# Problems with This Chatbot

This is not a perfect chatbot. It has many problems:

1. No Message Roles
   - If we check the "chat_history", there are "no message roles".
   - We cannot interpret who said what.

2. Growing Memory
   - chat_history keeps increasing throughout the conversation.

3. Token Limit Problem
   - Sending the entire history every time can eventually exceed the model's context window.

4. Higher Costs
   - More tokens are sent with every request, increasing API usage/cost.

5. No Persistent Storage
   - History is lost when the program stops.

# Message Placeholders

A message Placeholder in LangChain is a special placeholder used inside a ChatPromptTemplate to dynamically insert chat history of a list of message at runtime

Now suppose our customer has only talked to the chatbot 1 time only:
    HumanMessage(content = "I want to request a refund for my order #12345")
    AIMessage(content = "Your refund request for order #12345 has been initiated. It will be processed in 3-5 business day.")
This text has stored in a .txt file. But ideally this text is stored on the cloud.
But now the customer has no patience, he came again on the next day to talk to the chatbot asking for the refund. For this task, the chatbot needs to get the history of what they had talk about previously. So we need to load those previous messages that can be done through MessagePlaceholder concept.
