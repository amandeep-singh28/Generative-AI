# What is Streamlit?

Streamlit is a Python framework used to quickly create interactive web applications for Python/ML/GenAI projects.

It allows us to create a UI directly from Python code.

# 1. Import Streamlit

import streamlit as st

st is the conventional alias used for Streamlit.

# 2. Display Heading

st.header("Researcher Tool")

Displays a heading in the web application.

Other commonly used functions:
- st.title()
- st.subheader()
- st.write()

# 3. Select Box

paper_input = st.selectbox(
    "Select Research Paper Name",
    ["Paper 1", "Paper 2", "Paper 3"]
)

Creates a dropdown menu.

The selected value is stored in:
paper_input

Similarly:
- style_input = st.selectbox(...)
- length_input = st.selectbox(...)

# 4. Text Input

user_input = st.text_input("Enter your prompt")

Creates a text field where the user can enter input.

The entered value is stored in:
user_input

# 5. Button

if st.button("Run"):
    result = llm.invoke(prompt)
    st.write(result.content)

st.button() creates an interactive button.

The code inside the if block executes when the user clicks the button.

# 6. Display Output

st.write(result.content)

Displays the result in the Streamlit UI.

- Streamlit → User Interface

- LLM → Generates response

# Why Use PromptTemplate Over f-strings?

1. Default validation
2. Reusable
3. LangChain ecosystem

## Default Validation (validate_template=True)

It checks whether the variables used in the prompt template match the variables provided in "input_variables".

Example:

from langchain_core.prompts import PromptTemplate

prompt = PromptTemplate(
    template="Explain {topic} to a {audience}",
    input_variables=["topic", "audience"],
    validate_template=True
)

If a required variable is missing or incorrectly defined, LangChain can raise an error.

## Reusable

A PromptTemplate can be saved as a JSON file:

template.save("template.json")

This allows the prompt template to be shared separately from the Python code.

The saved template can later be loaded:

from langchain_core.prompts import load_prompt

template = load_prompt("template.json")

Then we can use it normally:

prompt_template.invoke({
    "paper_input": paper_input,
    "style_input": style_input,
    "length_input": length_input
})
